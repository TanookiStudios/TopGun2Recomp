Top Gun 2 for Linux (64-bit Intel/AMD)

1. Unpack this folder anywhere you like (your home folder is fine).
2. Double-click TopGun2, or run ./TopGun2 in a terminal from this folder.
3. The first time, the launcher asks for your own Top Gun: The Second Mission
   (USA) .nes file. Nothing from the game ships with this download.

Settings and saves are kept in this folder, next to the program.
Optional menu shortcut: run ./install-shortcut.sh once to add Top Gun 2 to
your application menu (it only writes to ~/.local/share).

Needs a desktop with working OpenGL graphics (any normal Linux desktop).
